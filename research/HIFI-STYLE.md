# Hourberry · Hi-fi 视觉规范（给生成 hi-fi 的 AI 看）

先读这份，再看截图。**这份规范和截图冲突时，以这份为准。**
功能、流程、文案都以原型为准（`core/index.html`、`RULES.md`）。**hi-fi 只换皮，不改结构**：不加屏、不加按钮、不加信息、不改文案。

## 0. 参考什么、学什么
| 参考 | 比重 | 学 | 不学 |
|---|---|---|---|
| Gentler Streak（`research/gentler-streak/`） | 主 | 干净、层级清楚、像上线的 iOS app；大标题是一句结论；灰色块分组；sheet 统一模板；浮动胶囊 tab；角色只在关键时刻出现 | 它的橙色、它的功能（运动、图表） |
| Ahead（`research/ahead/`） | 辅 | 有趣的部分：选项有性格、小庆祝、浅色的分类卡、一屏只问一件事 + 底部一个全宽主按钮 | 它的紫色、emoji 当图标、游戏化地图、课程形式 |

学的是**思路**，不是外观。不要复制它们的颜色、插画、图标或布局细节。
截图里夹着别的 app（Cal AI、WHOOP、Bevel、Snapchat 等），不要看。两份 `notes.md` 里有编号索引。

## 1. 整体感觉
- 一句话：**像 Apple 自带 app 一样干净，有趣的地方全交给果子角色和文案。**
- 底色浅灰，内容放在白色圆角块里。分区靠色块，**不用描边，不用分割线**。
- 整个 app 只有**一个主色**。其他地方都是黑、白、灰。
- 留白多。一屏只有一个最重要的东西。

## 2. 字体
- UI 全部用 **SF Pro**（iOS 系统字体）。网页里写 `-apple-system, BlinkMacSystemFont, "SF Pro Text", system-ui, sans-serif`。
- 大数字和大标题用 **SF Pro Rounded**（网页里写 `ui-rounded, "SF Pro Rounded", system-ui`）。圆角字体呼应果子的形状。只用在：页面大标题、时间、人数这类大数字。
- 不要引入别的字体，不要用衬线体，不要用手写体。
- 字号层级（pt）：
  | 用途 | 字号 / 粗细 |
  |---|---|
  | 页面大标题（Plans、Chats） | 30 / Heavy (800) |
  | sheet 标题、卡片标题 | 20–22 / Bold |
  | 行标题、按钮 | 16–17 / Semibold |
  | 正文 | 15–16 / Regular |
  | 辅助信息（距离、时间、"Free till 10"） | 13 / Regular，灰色 |
  | 分组标签（CLOSE FRIENDS） | 12 / Semibold，全大写，灰色 |
- 数字和单位：数字大、黑；单位小一号、灰色（例："7:00" 大，"PM" 小）。

## 3. 颜色
**主色用在：主按钮、选中状态、角标、自己的果子，以及每屏"唯一的重点"（见第 3.5 节）。**

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#1C1C1E` | 主文字 |
| `--mute` | `#8E8E93` | 次要文字、图标 |
| `--canvas` | `#F2F2F7` | 页面底色 |
| `--card` | `#FFFFFF` | 卡片、sheet |
| `--g1` | `#F3F3F7` | 卡片里的灰色块、未选中的 chip |
| `--g2` | `#E8E8ED` | 按下状态 |
| `--accent` | **待 Dakota 定**（建议一个莓果色，比如树莓红 `#E5446D`） | 主按钮、选中、角标 |
| `--accent-tint` | 主色 10% 透明度 | 选中 chip 的底色 |
| `--free` | `#34C759` | **只用于"有空"**的小绿点。不能拿来做别的。 |

- 果子角色可以有多种颜色。UI 大部分不跟着角色变色，例外见第 3.5 节（卡片顶部的浅色底）。
- 不要渐变背景、不要彩色卡片铺满屏、不要霓虹或发光效果（Gentler 的发光大数字不学）。
- 要支持深色模式：底色 `#000`，卡片 `#1C1C1E`，主色不变。

## 3.5 重点强调（11/11 加：上一版 hi-fi 每样东西一样重，看起来很平、很低级）
**每一屏先回答："用户一眼应该看到什么？"那个东西必须比别的都重，其他东西让路。** Gentler 每屏都有一个大结论 + 一块有颜色的状态区；Ahead 每类内容有自己的浅色卡。我们照这个思路做：

1. **一屏只有一个"英雄区"，给它颜色。**
   - Plan 卡片：顶部人群那一块用 **host 果子颜色的很浅版本**（饱和度低、亮度高，约 8–12% 不透明）当底色，每张卡因此有自己的样子。不要用灰色。
   - 自己的 profile：顶部那一块用用户在捏果子时选的背景色。
   - Recap：插画就是英雄区。
2. **"为什么和你有关"永远最突出。** 像 "Lena's in"、"You both want to go"、"Free till 9" 这种一句话理由，用主色浅底（accent-tint）+ 主色字 + 那个人的小果子。不要做成和其他白色小胶囊一样。
3. **紧迫信息变重。** 座位 ≥3 时是普通白胶囊；**≤2 时变成实心深色**（"2 seats left"）；满了写 "Full · waitlist"。不要所有 pill 一个样。
4. **留言要像人说的话。** host 的留言做成**对话气泡**，尾巴指向 host 的果子，不要做成和座位数一样的胶囊。
5. **列表里的图标放进小色块。** 像 Good to know、设置、地点类型这些行：图标放在 32×32 的圆角方块里（圆角 10），方块用浅色底。不同类型可以用不同的浅色（停车、付钱、证件、地点各一个），学 Ahead 的分类卡和 iOS 设置。这些浅色只用在小方块里，**不能铺满整张卡**。
6. **字重拉开。** 一屏里最多三级：大标题（Heavy）→ 行标题（Semibold）→ 辅助（Regular 灰）。辅助信息不要用黑色，标题不要用 Regular。
7. **自检：** 把截图缩小到手机的 1/4 大小，还能一眼看出"这一屏讲什么、我该点哪里"。看不出来就是重点不够。

允许的颜色总表：一个主色（+ 它的浅底）、果子的颜色、果子颜色的极浅底（只在英雄区）、小图标方块的几种浅色、有空的绿点。除此之外都是黑白灰。

## 4. 形状、阴影、玻璃
- 圆角：卡片 16，sheet 顶部 24，按钮和 chip 用全圆角（胶囊），头像是果子形状（不规则的圆，不是正圆）。
- 阴影只有三档，很淡：
  - 卡片 `0 2px 12px rgba(0,0,0,.05)`
  - 浮在地图上的东西 `0 8px 24px rgba(0,0,0,.08)`
  - 浮动 tab `0 10px 30px rgba(0,0,0,.12)`
- 玻璃（只用在浮在地图或内容上的东西：tab 胶囊、地图上的按钮、free 那一堆、地图上的抽屉）：
  `background: rgba(255,255,255,.72); backdrop-filter: blur(20px) saturate(180%)`

## 5. 间距
- 屏幕左右边距 16。
- 页面标题 → 第一块内容 16；同一组里的块之间 8；不同组之间 32；分组标签 → 内容 12。
- 卡片内边距 16。列表行高至少 56，头像 44。
- 点按区域至少 44×44。

## 6. 组件（照原型做，只换皮）
- **Tab**：底部悬浮的玻璃胶囊，4 个：Map / Plans / Chats / People。选中的那格有浅灰底，图标 + 文字变黑。
- **主按钮**：全宽胶囊，主色底白字，高 52。一屏最多一个主按钮。次要操作用灰色块按钮或文字链接。
- **Sheet**：所有底部弹层用同一个模板：顶部拖动条 → 粗标题 → 内容 → 底部一个全宽主按钮。不放右上角 ×，向下滑或点外面关闭。
- **Chip**：未选中是 `--g1` 底黑字；选中是 `--accent-tint` 底、主色字，或者黑底白字（全局统一选一种）。
- **卡片（plan card）**：上面是人（果子一串）+ host 的留言气泡，右上角座位数小胶囊，下面标题 + 时间 · 距离，再下面地点行。
- **图标**：SF Symbols 风格，线宽 2，圆角端点。选中状态用**实心**图标，不要加描边框。
- **列表**：没有分割线，行和行之间靠留白。

## 7. 有趣从哪里来（只在这几个地方）
1. **果子角色**：头像、free 那一堆、空状态、加载页、成功时刻。角色只在关键时刻出现，设置页、表单里不放（学 Gentler）。
2. **文案**：短、口语、有一点幽默（学 Ahead 的"选项有性格"）。不要改原型文案；要改先列出来给 Dakota 看。
3. **小动效**：果子掉进那一堆、加入时果子跳一下、发出计划时果子聚成一串。时长 200–350ms，用弹簧曲线。
4. **小庆祝**：加入成功、计划凑满人时出现一次。不要每一步都庆祝。

## 8. 不要做
- 不要 emoji（不当图标、不当装饰）。
- 不要真人照片，头像一律是果子角色。
- 不要描边线框、分割线、虚线框。
- 不要第二个主色，不要彩虹配色（第 3.5 节里的浅色只能出现在英雄区底色和小图标方块里）。
- 不要让一屏里所有东西一样重：每屏必须有一个最突出的东西（第 3.5 节）。
- 不要大段渐变、玻璃拟态到处用、新拟态（neumorphism）。
- 不要加原型里没有的信息（评分星星、标签云、统计图）。
- 不要像团购或 Groupon（价格大字、促销标签、倒计时抢购）。
- 不要把 Sponsored 做得比普通地点更显眼。
