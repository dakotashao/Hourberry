# Hourberry · 插画需求（给生成插画的 AI）

用我们的果子角色来画。角色的样子以 Dakota 给你的角色稿为准，这份文件不重新定义角色，只说明：画什么、在哪里用、什么感觉。

## 1. 先了解产品（一段话）
Hourberry 帮人在突然有空的时候，几秒钟内加入朋友的局，或者自己发起一个局。品牌故事："A berry is small, sweet, and best shared." **一颗果子就是一个人，几颗凑在一起就是一个局。** 所以插画里永远是一串果子在一起做一件事，几乎不出现一颗果子单独待着的画面。

## 2. 感觉：从两个参考 app 学什么
参考截图在 `research/gentler-streak/` 和 `research/ahead/`。**只学感觉，不要照抄它们的角色、颜色或构图。**

**Gentler Streak（主要参考）**
- 角色就是插画的主角，场景只是陪衬。场景很简单：一个太阳、几朵云、一棵棕榈树，交代清楚"在哪儿"就够了。
- 平面插画，**没有黑色描边**，形状靠色块区分，带一点很淡的颗粒质感。
- 角色有道具、有动作（戴墨镜、拿着球、在跑），一眼就能看出它在干什么、心情怎样。
- 留白多，插画不铺满画面，四周是干净的底色。
- 偶尔有手写体的小标注、虚线小路这种轻松的细节。

**Ahead（辅助参考）**
- 同一个角色有很多情绪变体，靠**表情和姿势**区分，不靠换角色。
- 形状圆、软、可爱，眼睛简单（点或小椭圆），嘴很小。
- 颜色柔和、偏浅，一个画面里颜色不多。
- 有"收集感"：小配件、小奖励物件，让人想集齐。

**合起来就是：** 简单的场景 + 有动作、有情绪的果子 + 平面无描边 + 柔和少量的颜色 + 大量留白。

## 3. 统一规则
- **风格：** 平面插画，无黑色描边，可以有很淡的颗粒质感。不要 3D、不要写实、不要大面积渐变、不要发光效果。
- **颜色：** 果子是整个 app 里唯一允许多种颜色的东西，每颗果子可以不同颜色。场景用很少的柔和颜色，饱和度低于果子，不能抢果子的风头。底色留白或很浅。
- **脸：** 简单。点状或小椭圆的眼睛，小嘴巴。情绪靠姿势、眉眼和道具表达。
- **画里不放文字：** 标题和说明由 app 自己写。也不要画任何真实品牌、店名或 logo（比如店招上不要写字）。
- **不要：** 真人、emoji 风格、复制 Gentler 的心形角色或 Ahead 的紫色小幽灵。
- **格式：** 透明背景 PNG（2x 和 3x）或 SVG。场景背景和果子分开出图（见第 5 节）。

## 4. 每张插画放在哪里、画什么

### A. Recap 顶部插画（最重要，数量最多）
局结束后的回顾页最上面。尺寸比例约 **16 : 9**（app 里大约 343 × 200 pt）。下面会接一句大字结论，例如 "You met 1 new person"。

插画由这次局的内容决定（11/11 定：只变场景，不随评价变）：

| 插画里的什么 | 由什么决定 | 怎么画 |
|---|---|---|
| 场景 | 局的类型 | 见下面的场景表 |
| 白天 / 晚上 | 局开始的时间 | 白天：太阳、浅色天空；晚上：月亮、星星、暖色灯光。室内场景通过窗外的天色或灯光区分 |
| 几颗果子 | 去了几个人 | 1–6 颗；两个人就是两颗面对面，人多就围成一圈。超过 6 个人也只画 6 颗，挤一点 |
| 新朋友 | 这次新认识的人 | 那颗果子头上多一片**新长的小叶子**（浅绿、小、翘起来） |

果子的表情统一是开心、放松，在做这个场景里的事（吃、唱、爬、聊天）。不按用户的评价变表情。

**场景（第一批 12 个）**
| 文件名 | 场景 | 画面里有什么 |
|---|---|---|
| `scene-tacos` | 塔可 / 吃饭 | 小桌子、几个塔可、一瓶辣酱 |
| `scene-ramen` | 拉面 | 吧台、冒热气的碗 |
| `scene-coffee` | 咖啡 | 窗边的小圆桌、咖啡杯 |
| `scene-drinks` | 喝一杯 | 吧台高脚凳、杯子、一串小灯 |
| `scene-dinner` | 晚饭 / 在家吃 | 长桌、几个盘子、蜡烛 |
| `scene-rooftop` | 屋顶 / 在家玩 | 夜空、星星、一串灯泡、矮墙 |
| `scene-karaoke` | 卡拉 OK | 麦克风、小屏幕、闪光的点 |
| `scene-climbing` | 攀岩 | 一面有彩色岩点的墙 |
| `scene-hike` | 散步 / 徒步 | 小路（可以用虚线）、山、太阳 |
| `scene-games` | 桌游 | 桌子、骰子、几张卡牌 |
| `scene-art` | 看展 / 演出 | 墙上几个画框，或者一个小舞台 |
| `scene-default` | 其他 / 不知道类型 | 一张野餐布、几片叶子。什么局都能用 |

### B. 加人成功页
有人刚被加为好友："Priya's in your bunch!" 画**两颗果子第一次碰在一起**：碰拳、击掌，或者叶子碰叶子。正方形，约 200 × 200 pt。文件名 `spot-added`。

### C. 空状态（正方形，约 160 × 160 pt，一颗或几颗果子）
| 文件名 | 用在哪 | 画什么 |
|---|---|---|
| `empty-plans` | Plans 页没有任何局 | 一颗果子坐着翻日历，表情期待 |
| `empty-people` | 还没有朋友 | 一颗果子在招手，旁边有一个空位 |
| `empty-chats` | 还没有聊天 | 两颗果子中间一个空的对话气泡 |
| `empty-nearby` | 附近没有局 | 一颗果子拿着望远镜 |
| `discover-done` | Discover 今天的卡看完了 | 一颗果子躺着，盖着一张卡片当被子，"明天再来" |
| `offline` | 没网 | 一颗果子拿着断了线的纸杯电话 |

### D. 加载页（已有，统一风格）
几颗果子慢慢聚成一串小点。下面 app 会写 "Got an hour? Make it ours."。文件名 `loading-bunch`，最好能拆成 4–5 帧，或者给 Lottie。

### E. Premium 页
一颗果子头上有一颗小星星，旁边几颗果子围着它。文件名 `spot-premium`。

### F. 兴趣选择页（新用户注册时的 "What do you like to do?"）
**只要一张插画，放在这一屏顶部。** 不给每个选项单独画图。
参考依据：Gentler 的选择列表（Set Status：Active / On a Break / Sick / Injured）每个选项只用一个单色线条小图标，整个 sheet 只在顶部放一张小插画。Ahead 的选项列表前面也只是一个小图标。两个 app 都没有给每个选项单独配插画。
- 文件名 `int-header`，约 200 × 140 pt：一颗果子站在中间，周围漂着几样东西（一个塔可、一个咖啡杯、一个岩点、一个骰子、一个麦克风），像在挑选。
- 选项卡片上的小图标**不归插画**，用 app 自己的图标库（单色线条，和 tab 图标同一套），由 UI 设计负责。

**不要放插画的地方：** 列表、设置、表单、聊天。角色只在关键时刻出现（这是从 Gentler 学的）。

## 5. 怎么出图（重要：控制数量）
如果每个场景 × 白天晚上 × 每种人数都画一张，会有几百张。所以请**分层出图**，由 app 拼起来：

1. **场景背景层**：12 个场景 × 白天 / 晚上 = 24 张，不画果子，中间下方留出放果子的位置。文件名例：`scene-rooftop-night`、`scene-coffee-day`。
2. **果子层**：1–6 颗果子各一种排法（一共 6 张），透明背景。果子用占位颜色，app 会按每个人的颜色换色。
3. **配件层**：新叶子（`acc-new-leaf`）、星星（`acc-star`），单独透明 PNG，app 叠在对应的果子头上。

其余的（B–F）各画一张整图就行。

不用一次画完。请先出这 3 张给 Dakota 确认风格：
